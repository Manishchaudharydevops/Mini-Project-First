# Agile Project & Sprint Analytics Suite

Mini Project 1 - GLA University, Department of Computer Engineering & Applications

A frontend-only Agile/Scrum web application built with React. It has a drag-and-drop Scrum board, task management, sprint management, sprint analytics (burndown chart and velocity) and a rule-based risk score. All data is saved in the browser using Local Storage. There is no backend, no database and no machine learning.

## Features

- Scrum board with Backlog, To Do, In Progress, Review and Done columns
- Add, edit and delete tasks (title, description, priority, assignee, story points, due date)
- Drag and drop tasks between columns
- Sprint management with start and end dates, add or remove tasks from a sprint
- Summary cards, burndown chart and velocity chart
- Risk score (0 to 100) with risk level and reasons
- Data stays after page refresh (Local Storage)
- Works on desktop and mobile

## Technologies

React, JavaScript, HTML5, CSS3, HTML5 Drag and Drop, Recharts, Local Storage, Git, GitHub, Vercel
